# PolyFold 업데이트 내역

## 2026-10-28

### 안내 문구를 쉽게 고쳤어요

- "절단면"이라는 어려운 말을 "단면 보기", "자르는 면"으로 바꿨어요.
- 단면 기능이 꺼져 있을 때는 "단면 보기가 꺼져 있어요. 켜면 잘린 모양이 보여요."라고 안내해요.
- "단면 자르기" 카드에 "켜면 자르는 면과 잘린 단면이 함께 보여요." 설명을 넣었어요.
- 문제의 힌트와 해설에서도 "절단면"을 "자르는 면"으로 바꿨어요.

### 접기 애니메이션을 조절할 수 있어요

- 접기 속도를 느리게(약 5초), 보통(약 3초), 빠르게(약 1.5초) 중에서 고를 수 있어요. 기본은 보통(3초)이에요.
- "접는 정도" 막대의 손잡이를 크게 만들고, 드래그하면 바로 재생이 멈추고 그 위치의 접힌 모양으로 볼 수 있게 했어요.
- 고른 접기 속도는 브라우저에 저장되어 다음에 열어도 유지돼요.

### 화면 문제 수정

- 태블릿에서 접기·단면 도구로 스크롤할 때 카드가 3D 무대를 덮던 문제를 고쳤어요.

### 확인

- 단위 테스트 42개 통과
- 브라우저 테스트 52개 통과 (프로젝트별로 일부 테스트는 건너뜀)
- 린트·빌드 통과

## 2026-10-27

### 앱을 처음 완성했어요

- 다섯 가지 입체도형(정육면체, 직육면체, 삼각기둥, 정사각뿔, 정사면체)을 3D로 보여 주고, 전개도로 펼쳤다 접었다 할 수 있게 했어요.
- 전개도를 직접 생성하고, 면이 겹치거나 빠지거나 이어지지 않는지 검사해요. 정육면체는 접을 수 있는 전개도 11가지를 모두 찾아 줍니다.
- 접기 슬라이더와 자동 접기 애니메이션을 넣었어요. 애니메이션을 줄이는 설정도 있어요.
- 자르는 면을 움직이고 방향을 바꾸면 단면의 모양, 둘레, 넓이를 바로 계산해서 보여 줘요. 단면이 생기지 않는 경우도 알려 줘요.
- 겉넓이와 부피를 계산하고, 공식과 숫자를 함께 보여 주는 계산 패널을 만들었어요.
- 2D 전개도 화면에서 면을 눌러 이름을 확인할 수 있고, 3D 화면과 같은 면이 함께 강조돼요.

### 도전과 교사 도구

- 전개도 판별, 입체 맞히기, 단면 예측, 측정의 네 종류로 8문제를 만들었어요.
- 답을 제출하면 정답과 해설을 보여 주고, 첫 시도에 맞히면 별 3개를 줘요. 두 번 틀리면 정답과 해설을 공개해요.
- 입체 맞히기 문제는 답을 제출하기 전까지 입체 이름을 무대에서 가려요.
- 별과 답안은 이 기기의 브라우저 저장소에만 저장되고, 다시 열어도 이어서 풀 수 있어요.
- 교사 화면에서 문제 세트(전체·기본·심화), 정답과 해설 공개, 학습지 인쇄, 진행 초기화를 할 수 있어요.

### 화면과 접근성

- 데스크톱은 갤러리·무대·도구의 3단 구성, 태블릿은 무대 아래 도구 패널, 휴대폰은 무대 아래 탭(접기·단면·측정·도전) 구성으로 바꿨어요.
- 키보드로 무대를 돌리고 확대·축소하고 접기를 실행할 수 있어요. 건너뛰기 링크, 보이는 초점 테두리, 화면 읽기 안내도 넣었어요.
- 색만으로 구분하지 않도록 면 이름과 모양 이름을 함께 표시해요.
- 처음에는 접힌 입체가 보이고, 전개도를 고르면 2D 전개도 화면으로 자연스럽게 바뀌어요.
- 도전 화면에서는 답을 제출하기 전까지 보기 전환을 잠가 정답이 미리 보이지 않게 했어요. 입체 맞히기 문제는 입체 이름도 가려요.
- 자르는 면의 테두리를 그려서 어느 방향으로 자르는지 더 쉽게 볼 수 있게 했어요.
- 태블릿 도전 화면에서는 문제가 더 빨리 보이도록 무대 높이를 줄였어요.
- 앱 설치와 오프라인 실행을 위한 아이콘과 서비스 워커를 넣었어요.

### 수학과 검증

- 삼각기둥 밑면의 높이를 바로잡아 겉넓이·부피 공식과 실제 값이 일치하도록 했어요.
- 자르는 면이 꼭짓점 하나만 스칠 때 단면이 생기지 않도록 처리했어요.
- 단위 테스트 42개로 다섯 입체의 면·모서리·꼭짓점, 겉넓이·부피, 전개도 11가지, 접었을 때 위치, 단면 모양, 문제 내용을 확인해요.
- 브라우저 테스트 49개로 데스크톱·태블릿·휴대폰에서 탐구, 접기, 단면, 도전, 교사 초기화, 키보드 사용, 접근성 검사, 오프라인 새로고침을 확인했어요.
- 자동 접근성 검사에서 심각한 문제가 없는 것을 확인했어요.
